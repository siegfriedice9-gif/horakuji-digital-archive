【Ver.8の変更】
1. 「ズームフェード」を削除しました。
   ・スライド切替演出は「ディゾルブ」「横スライド」の2種類です。

2. スライドショーを1～8の一巡で終了するよう変更しました。
   ・1 Before → 1 After → … → 8 Before → 8 After
   ・8 Afterを表示後、自動再生を終了します。
   ・8から1へ自動でループしません。

3. スライドショー中の人物選択動作を変更しました。
   ・左側の人物を選択した場合、スライドショーを終了します。
   ・選択した人物の「比較」画面へ移動します。
   ・その人物を起点にスライドショーが継続することはありません。

4. スライドショーの画像倍率はVer.7と同じく比較画面と共通です。
